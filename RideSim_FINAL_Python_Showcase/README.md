# RideSim Final Python Showcase

Phase 1 implementation: Euclidean cost matrix, greedy nearest-neighbour O(n^2), exact Kuhn-Munkres/Hungarian O(n^3), same-scenario comparison, distance savings, runtime benchmarking, tests, CLI, and browser showcase.

Run:
python -m unittest discover -s tests -v
python -m ridesim.cli
python -m ridesim.server

Then open http://127.0.0.1:8000

No third-party Python packages are required.
